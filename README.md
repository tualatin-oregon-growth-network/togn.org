# togn.org

This is the website of Tualatin Oregon Growth Network (TOGN). We are an organization focused on supporting the sustainable growth of Tualatin:

- Nurture and expand our trail networks for all users
- Encourage sustainable adaptation of housing, commercial and industry
- Socialize and have fun with like minded neighbors

## Technical Details

https://togn.org is hosted on GitHub and developed with Astro. There is a mailing list hosted on Google Groups on the togn.org workspace.
